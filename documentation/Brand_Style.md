# Brand Style - Supa-Neighbour

## 2. Colour Palette
 
### 2.1 Core Colours
 
| Role | Colour Name | Hex Code | Usage |
|---|---|---|---|
| Primary | Vibrant Teal | `#2A9D8F` | Primary buttons, active states, links, key highlights |
| Secondary | Citrus Yellow | `#E9C46A` | Badges, XP indicators, secondary actions, accents |
| Background | Clean White | `#FFFFFF` | Screen backgrounds, card surfaces |
| Text Dark | Charcoal | `#264653` | All body text, headings, labels on light backgrounds |
| Text Light | White | `#FFFFFF` | Text on dark/coloured backgrounds (e.g. filled buttons) |
| Success | Mint | `#69B578` | Success states, completed task indicators, confirmations |
| Error | Coral | `#F4A261` | Error messages, validation failures, destructive action warnings |

 
### 2.3 Colour Usage Rules
 
- Never use Coral (`#F4A261`) for anything other than errors or destructive actions
- Never use Mint (`#69B578`) for anything other than success or completion states
- Citrus Yellow must always pair with Charcoal (`#264653`) text — never white text on yellow (fails contrast)
- Primary Teal with white text passes WCAG AA (contrast ratio 4.6:1)
