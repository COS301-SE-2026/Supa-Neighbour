# Definition of Done

A user story is only considered Done when ALL of the following are true:

- [ ] Code is written and follows the team's style/Checkstyle rules
- [ ] Code has been peer-reviewed and approved via Pull Request
- [ ] All Acceptance Criteria in the issue are met
- [ ] Unit tests written and passing for new logic
- [ ] No new Checkstyle violations introduced
- [ ] Feature manually tested against the acceptance criteria
- [ ] Documentation/README updated if behavior changed
- [ ] Merged into main via PR (no direct pushes)
- [ ] Issue linked to the PR and closed automatically on merge
